# Rem Clicker 💙

A fan-made, Cookie Clicker-style incremental game built with plain HTML, CSS, and JavaScript. No build tools or Railway needed.

## Run locally

Download or clone the repository and open `index.html` in a browser. The game saves progress in your browser using localStorage.

## Add Rem artwork

Create an `assets` folder and add an image named `rem.png`. It will replace the default blue-heart placeholder. You can also temporarily preview your own image using the **Choose Rem image** button; that preview is not persisted across reloads. Use artwork you have permission to use.

## Add the click sound

Place the audio clip at `assets/guragura.mp3`. Clicking Rem will play the clip when sound is enabled. Audio is optional until you provide the file.

## Hosting later

This is a static site. It can be deployed on a static host such as GitHub Pages, Cloudflare Pages, or Netlify. Railway is optional and is not needed to run the game. A private repository may require additional host authorization or a paid plan depending on the host.
